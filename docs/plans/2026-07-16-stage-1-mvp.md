# Stage 1 MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task.

**Goal:** Build the complete Stage 1 Omnichannel AI Customer Operations MVP as secure, runnable vertical slices, followed by optional payment and logistics modules.

**Architecture:** A TypeScript modular monolith in a pnpm/Turborepo monorepo with separate owner and client applications, a NestJS/Fastify API, SSE realtime gateway, PostgreSQL tenant isolation, Redis/BullMQ asynchronous processing, and provider-neutral adapters. Business state, audit, and outbox commit atomically; all external effects are idempotent and reconcilable.

**Tech Stack:** Node.js LTS, pnpm, Turborepo, Next.js, React, TypeScript strict mode, Tailwind CSS, NestJS, Fastify, Drizzle ORM, PostgreSQL with RLS and pgvector, Redis, BullMQ, Vitest, Playwright, Testcontainers, OpenAPI/JSON Schema, OpenTelemetry, S3-compatible storage, LiteLLM-compatible AI gateway, and Temporal in the durable-workflow milestone.

---

## Plan Rules

- Follow red-green-refactor for every behavior change.
- Do not add Stage 2 routes, commands, tools, jobs, or navigation during Stage 1.
- Do not use production credentials or customer data in local/test/staging.
- Do not implement a dependent task while its gap-register gate is OPEN.
- Run lint, typecheck, tests, build, and high-severity dependency audit before closing each milestone.
- Git commit steps begin only after this workspace is initialized as a repository with user approval.
